# 楓谷生存戰記 v0.3.1｜手機視窗修正版

## 修正內容
- 修正手機畫面中的升級／選擇視窗被遊戲畫布裁切的問題。
- 手機上的對話視窗改為固定在整個瀏覽器視窗上顯示。
- 選項過多或螢幕高度不足時，視窗內容可上下滑動。
- 手機版職業與升級選項改成單欄，避免卡片被擠壓。
- 保留手機虛擬搖桿、桌機鍵盤、戰鬥與升級功能。

## 更新方式
1. 解壓縮 ZIP。
2. 將新版 `index.html` 覆蓋 GitHub repository 根目錄的舊檔。
3. Commit changes，等待 GitHub Pages 部署完成。
4. 在 iPhone Safari 重新整理；若仍是舊版，關閉分頁再重新開啟，或清除網站快取。

此修正尚需在實際 iPhone 裝置上測試。
